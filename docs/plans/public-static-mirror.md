# FlowCut 静态剪辑兼容模式

## 目标

把核心的剪辑决策体验发布为可嵌入作品集子目录的纯静态应用，不依赖账号、服务端、外部 CDN 或任何模型凭据。

## 验收链路

1. 用户填写身份、受众、平台、时长、剪辑目标、交付时间与素材观察。
2. 本地决策引擎生成三条剪辑路线，展示收益、代价、素材锚点与适配分。
3. 用户确认路线后得到覆盖完整时长、首尾连续的真实剪辑时间线。
4. 用户可下载 Markdown 剪辑单与 JSON 时间线。
5. 本地评分与观察会生成下一版修订动作，并写回下载文件。
6. 所有运行时资源使用相对路径与系统字体；构建产物经过密钥扫描并附 SHA-256 清单。

## 输出

- 源文件：`mirror-src/`
- 构建命令：`bun run build:public-mirror`
- 可发布产物：`public-mirror/`
- 作品集目标目录：`mirrors/flowcut-ai-studio/`
