# VisionCut AI 使用说明

VisionCut AI 是意图驱动、本地优先的视频创作工作台。你先说明想要什么，系统再用真实素材证据生成可审阅方案；任何会改变时间线的 AI 操作都必须经过确认，并可撤销或恢复。

## 1. 选择运行方式

### 公网版本

打开 [https://flowcut-ai-studio.vercel.app](https://flowcut-ai-studio.vercel.app)。网页可以直接使用，但素材、项目数据和浏览器缓存位于当前浏览器的存储位置，网站不能替你指定磁盘。

### D 盘本地版本

在 D 盘仓库中运行：

```powershell
.\start-web.ps1
```

启动器会：

- 启动或安全复用只监听 `127.0.0.1` 的本地服务。
- 打开 VisionCut 专用 Chrome/Edge Profile。
- 把该 Profile 的 IndexedDB、OPFS、缓存、下载和临时目录放到 `D:\VisionCut-Data`。
- 不读取或修改日常浏览器 Profile。

完整参数、自检和边界见 [Windows D 盘本地数据启动](./windows-d-drive-local.zh-CN.md)。Chrome/Edge 程序本身、Windows 日志和页面文件仍可能位于 C 盘，因此不能把它表述成操作系统级“C 盘零写入”。

## 2. 推荐的第一次创作

1. 在 Home Studio 输入成片目标，例如：

   > 把三段创业者口播做成 60 秒竖屏短片，删除明显低能量停顿，开头先给结论，字幕简洁，最后保留行动信息。

2. 拖入或选择素材，等全部文件通过预检。
3. 点击“开始设计”，进入项目。
4. 保持“指导模式”，先完成“理解 → AI 配方 → 故事图 → 交付”。
5. 需要阈值、切口、B-roll、字幕密度、响度和多版本控制时，再切换“专业模式”。

指导模式强调结果和下一步；专业模式保留完整参数与传统多轨精修能力。两种模式使用同一项目，不会创建两个副本。

## 3. 导入素材

文件选择、页面粘贴和时间线拖放都会经过同一套预检：

- 每个文件不超过 4 GiB。
- 单批不超过 12 GiB，最多 20 个文件。
- 校验文件头、MIME、容器、编解码、损坏状态和浏览器存储容量。
- 失败文件不会混入已通过的素材，界面会给出具体原因。

浏览器只读取你主动选择的文件，不会扫描整个 D 盘。公网版本不会因为选择文件就自动把原片上传到模型或 ChatCut。

## 4. 十个创作工作面

| 工作面 | 用途 |
| --- | --- |
| 项目 | 查看真实素材、时长、轨道、未使用素材、版本和风险 |
| 理解 | 对选中视频做本地帧差、亮度、RMS、Peak、音频活动和段级转写分析 |
| 协作 | 导出 ChatCut v2 交接包，校验并导入结果，查看审计记录 |
| AI 配方 | 选择口播精剪、长转短、播客、活动、产品、教程、旅行、赛事、广告等流程 |
| 制作组 | 编排 Director、Story、Camera、Editor、Color、Sound、Growth 七个角色 |
| 故事图 | 在 Creative Canvas 中拖动、连接、缩放和排序节点，经审阅同步时间线 |
| 视觉实验室 | 管理原创镜头和待生成视觉概念；未连接图像模型时不会伪装为已生成 |
| 开放素材 | 搜索 Openverse，保留来源、许可和署名信息 |
| DNA | 管理只由明确决策形成的 Creator DNA，可暂停、撤销、导出或删除 |
| 交付 | 预检比例、字幕、响度和多版本制作任务，进入真实本地导出器 |

## 5. 本地素材理解与自动初剪

在“理解”工作面选择视频并点击“开始本地分析”。当前可信证据包括：

- 带时间戳的帧差和亮度采样。
- RMS、Peak 和音频活动区间。
- 导入字幕或本地 Whisper 产生的段级转写。
- 素材指纹、分析版本、来源和能力限制。

分析后可生成低能量候选或多素材初排。先逐个查看切口的时间码、理由、证据和风险，再批准并应用。执行器会再次检查素材指纹、场景和时间线是否变化；整组修改原子写入，失败不会留下半成品，并可一次撤销。

亮度、音量和帧差不是人物、物体、情绪或内容含义。没有相应证据时，VisionCut 会明确显示限制，不生成虚构结论。

## 6. 导演蓝图与专业参数

“AI 配方”会把意图转换成版本化导演蓝图。专业模式可控制：

- 静音阈值与切口余量。
- 场景灵敏度与 B-roll 密度。
- 字幕密度与推近强度。
- 填充词策略和目标响度。
- 1 至 6 个交付版本。

这些参数会进入执行策略、证据门槛和交付清单，不只是装饰控件。生成方案后，需要逐项接受或拒绝；修改素材、分析或关键参数会使旧方案失效并要求重新审阅。

## 7. 七角色制作组

默认“本地”模式不调用大模型，只让七个角色依据当前意图、MediaIndex、转写和上游产物生成可审阅计划。每个产物都记录角色、依赖、输入指纹、证据、限制、摘要和会话修订。

需要更强推理时，打开“模型与隐私”：

1. 选择 OpenAI、Anthropic 或 Gemini。
2. 输入自己的 API Key 和模型名。
3. 保存到当前标签页会话，并执行最小连接测试。
4. 回到制作组，选择 BYOK 后运行已批准角色。

Key 不写入项目、IndexedDB、数据库或日志，关闭标签页后清除；不接受自定义上游 URL。测试和正式调用可能由对应模型平台按你的账号计费。公网部署只有配置了分布式限流时才开放 BYOK 代理，否则会安全拒绝；本地免费模式不受影响。

## 8. Story Graph 与专业精修

Story Graph 是主要结构工作面，不是时间线的装饰视图：

- 素材、场景和转写节点带真实来源。
- 人物、情绪和声音节点只有在用户明确创建时才标为草稿。
- 支持拖动、连线、缩放、适配视口、版本历史和多窗口冲突检查。
- 排序变化必须预检并确认，才会原子同步到时间线。

时间线仍用于专业精修：裁切、移动、多轨编排、调速、静音、转场、关键帧、遮罩和效果。指导模式默认弱化时间线；专业模式可随时打开。

## 9. Creator DNA

Creator DNA 默认透明、可控，不训练个人模型。它只记录批准、拒绝、应用、撤销、恢复和确认交付等明确动作，并保存来源项目、时间和可撤销决策记录。

DNA 建议只在当前选项仍为“自动”、且不与本次文字意图冲突时参与规划。你可以暂停学习、撤销单条记录、删除项目账本、导出 JSON 或彻底删除本地档案。原片、字幕全文和 API Key 不进入 DNA。

## 10. ChatCut 协作

VisionCut 与 ChatCut 使用严格的 v2 交接协议：

1. 完成导演方案审阅。
2. 在“协作”中导出或复制交接包。
3. 在启用了 ChatCut 的 Codex 任务中显式附上对应素材并提交。
4. 下载 ChatCut 结果 JSON。
5. 回到 VisionCut 导入结果。
6. 检查 handoff ID、基线版本、素材和时间线指纹、操作差异及风险。
7. 只应用批准的操作。

导入采用原子命令并保存回执，可撤销和重做。素材或时间线在交接后变化时，旧结果会被阻止。当前不是两个产品之间的实时双向时间线同步，也不会静默上传视频。

## 11. 项目版本

新版本同时保存项目结构、场景、时间线、意图、蓝图、Story Graph、Agent 会话状态和转写修订，并记录素材指纹和完整性摘要，不复制原始媒体。

版本列表会明确区分：

- **完整可恢复**：项目、时间线和创作状态一起恢复。
- **时间线可恢复**：兼容旧快照，只恢复项目和时间线。
- **仅引用**：没有可恢复快照。

恢复会创建新版本；待执行建议会清空并要求重新审阅，避免把旧批准套到新状态。

## 12. 导出与交付

“交付”工作面先生成制作清单并做阻塞检查，包括目标比例、字幕、响度、素材状态、许可提示和 1 至 6 个版本。清单、排队、渲染、下载和上传是不同状态，不会把 JSON 清单冒充成视频文件。

预检通过后，使用“打开本地视频导出器”生成 MP4 或 WebM。多版本任务会按当前浏览器渲染器的真实能力逐项执行；未渲染或失败的版本保留明确状态。D 盘专用启动器默认把下载放到 `D:\VisionCut-Data\Downloads`。

## 13. 手机和平板

- 手机底部工作面用于意图、素材、AI、预览、故事和时间线切换。
- 平板采用可折叠检查器与主画布，适合完成完整 AI 审阅流程。
- 触屏和不超过 1199px 的布局使用至少 44px 操作目标；桌面鼠标布局保持紧凑。
- 复杂多轨精修仍以桌面端效率最高。

本地媒体分析和导出会受设备性能、浏览器内存及后台限制影响；长素材建议使用桌面端和 D 盘专用 Profile。

## 14. 当前真实边界

- 当前默认是无需账号、无需 Key、无需付费服务的本地浏览器闭环。
- PostgreSQL schema、迁移和 RLS 已建立，但当前公开版本仍以 IndexedDB/OPFS 为运行时真相，不提供跨设备实时协作。
- 没有云对象存储、后台 worker、长任务队列、自动发布或服务端多规格渲染。
- 没有证据支持时，不提供人物/物体识别、说话人分离、情绪判断、词级时间码、留存率或爆款预测。
- Openverse 结果仍需遵守每个素材的具体许可和署名要求。
- 清除专用浏览器 Profile 会同时清除仅保存在该 Profile 中的本地项目；重要版本和清单应先导出。

完整实现状态以 [PART 1-8 完整性矩阵](./architecture/visioncut-part-1-8-completion-matrix.md) 为准。
