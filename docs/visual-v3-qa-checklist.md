# Visual V3 逐仓 QA 清单

每个仓库只有在下列证据全部存在时才可合并：

## 视觉真实性

- [ ] 本轮新增位图文件数不少于 50。
- [ ] 50 个文件内容哈希互不重复。
- [ ] 50 条 manifest 记录字段完整，文件与代码引用一一对应。
- [ ] 每张图对应明确人物、处境、动作、产品状态和结果。
- [ ] 无水印、无第三方商标、无乱码和无法核实的文字。
- [ ] 50/50 图片可解码；尺寸元数据与自然尺寸一致。
- [ ] 核心旅程可自然访问至少 20 张；其余有明确案例/章节入口。
- [ ] 图片没有被纯图标、CSS 渐变、重复裁切或改名副本替代。

## 产品闭环

- [ ] 首次使用不被登录阻挡。
- [ ] 输入/场景 → 至少两个可比较方案 → 用户确认 → 可带走交付 → 反馈回流完整。
- [ ] 反馈会改变下一轮，或以可验证理由明确保持不变。
- [ ] 公开文案先写人和处境，技术说明后置。
- [ ] 不出现内部成本、评审、招聘、部署自夸等元话术。
- [ ] README 入口、命令、功能和限制与当前实现一致。

## UI、移动端与无障碍

- [ ] 320/390/430/1440 宽度无页面横向溢出。
- [ ] 主要触控目标不小于 44px。
- [ ] 键盘可完成核心流程，焦点样式可见。
- [ ] 图片 alt 与画面一致，装饰图使用空 alt。
- [ ] 支持 `prefers-reduced-motion`。
- [ ] 核心流程无破图、console error、page error、failed request。
- [ ] 首屏只加载必要图片，其余懒加载；布局无明显跳动。

## 安全、构建与发布

- [ ] 项目原有测试与新增测试全部通过。
- [ ] 生产构建与静态导出成功。
- [ ] 当前树、可达历史、新增图片、构建产物 Gitleaks 为 0。
- [ ] 独立高置信凭据规则为 0；未向 provider 验证任何候选。
- [ ] PR CI 通过，合并后的默认分支 exact SHA CI 通过。
- [ ] 部署记录可追溯到 exact SHA；线上引用 50/50 返回 200。
- [ ] 当前大陆网络主入口 200；不夸大为永久全网 SLA。
