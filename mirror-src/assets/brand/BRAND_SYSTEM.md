# FlowCut brand system

## Idea

FlowCut is the cut point that returns as an evidence loop. The mark combines an angular `F`, a coral diagonal cut, and a cyan proof node carried back by a return stroke. It expresses the product behavior: make a choice, ship the cut, observe the result, and let that evidence change the next choice.

## Promise and voice

- Promise: make the next cut accountable.
- Chinese product line: `让下一刀，有据可回。`
- Voice: precise, calm, specific, and owned by the creator.
- Never imply autonomous publishing, hidden uploads, model understanding, or availability that has not been verified.
- Never present the public product as a demo, contest entry, or compatibility fallback.

## Color

| Token | Value | Role |
| --- | --- | --- |
| Ink | `#080b0f` | product surface and wordmark |
| Paper | `#eef4e9` | primary text and light panels |
| Signal lime | `#b9ff66` | recommendation and forward action |
| Proof cyan | `#58e6ff` | evidence and feedback |
| Decision coral | `#ff8d5c` | trade-off, cut point, and explicit consent |

## Mark usage

- Keep one-quarter of the mark width as clear space.
- Use the supplied SVG unchanged; never redraw its cut angle or evidence node.
- Minimum digital size is 32 CSS pixels. At smaller sizes, use the mark without the wordmark.
- Use the lime tile on ink or paper surfaces. The mark remains local and self-hosted.
